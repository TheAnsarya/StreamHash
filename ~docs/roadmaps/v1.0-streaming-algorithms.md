# 🚀 StreamHash v1.0 Roadmap

## Overview

StreamHash v1.0 focuses on delivering high-performance streaming implementations of 8 non-cryptographic hash algorithms that traditionally require full data in memory.

## 📋 Milestone Breakdown

### Phase 1: Core Infrastructure ✅

**Target: Week 1**

- [x] Project structure and solution setup
- [x] `IStreamingHash<T>` interface definition
- [x] `StreamingHashBase<T>` abstract base class
- [x] ArrayPool memory management
- [x] Unit test infrastructure
- [x] Benchmark infrastructure

### Phase 2: MurmurHash3 Family ✅

**Target: Week 1-2**

- [x] MurmurHash3-32 streaming implementation
- [x] MurmurHash3-128 (x64) streaming implementation
- [x] Comprehensive test vectors
- [x] Performance benchmarks

### Phase 3: SipHash Family ✅

**Target: Week 2**

- [x] SipHash-2-4 streaming implementation

### Phase 4: SpookyHash ✅

**Target: Week 2-3**

## 🔧 Technical Requirements

### .NET Version

- Target: .NET 10
- Language: C# 14

### SIMD Support

- SSE2 (baseline for x64)
- AVX2 (optional, for HighwayHash)
- ARM NEON (for ARM64 support)

### Memory Management

- Zero allocations in hot paths
- ArrayPool for internal buffers
- Stackalloc for small temporaries

## 📝 Release Criteria

### v1.0.0 Release Requirements

1. All 8 algorithms implemented and tested
2. Streaming consistency verified (chunked = one-shot)
3. Performance within 10% of reference implementations
4. 95%+ code coverage
5. Complete XML documentation
6. NuGet package published
