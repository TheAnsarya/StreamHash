### Groestl MixBytes Optimization (Groestl.cs)

- Rewrote `MixBytes` to process 2 columns at a time instead of 1
- Pre-fetches all 40 GF(2^8) multiplication results per column pair upfront
- Eliminates temporary `_tempCol` buffer - reads directly from state
- Better cache utilization through interleaved column processing
- Maintains correctness (all tests pass)

### JH Linear Transform SIMD (Jh.cs)

- Added `ApplyLinearTransformSsse3()` method using SSSE3 intrinsics
- Processes 16 bytes (8 pairs) at a time using Vector128
- Uses byte shuffles to separate even/odd bytes, then recombines
- Implements b <<< 1 rotation using shift + AND + OR pattern
- Falls back to scalar implementation when SSSE3 not available
